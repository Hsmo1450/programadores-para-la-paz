El login es el proceso mediante el cual una aplicación verifica la identidad de un usuario antes de permitirle acceder al sistema. Gracias a la autenticación, solo las personas autorizadas pueden utilizar determinadas funciones. Algunas rutas deben estar protegidas porque contienen información privada o permiten realizar acciones importantes dentro de la plataforma. Esto ayuda a mantener la seguridad y la integridad de los datos. No deben exponerse públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni cualquier otra información sensible de los usuarios.
