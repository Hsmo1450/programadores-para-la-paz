Al ejecutar el comando node server.js, Node.js inicia la aplicación y pone el servidor en funcionamiento. En la terminal aparece el mensaje "Servidor ejecutándose en puerto 3000", indicando que el servicio está listo para recibir solicitudes.

Cuando se visita la ruta principal (/) en el navegador, se muestra el mensaje "Servidor activo y funcionando".

Cuando se visita la ruta /estado, el servidor responde con un objeto JSON que indica el estado actual del servicio:

{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
