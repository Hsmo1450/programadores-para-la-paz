Sistema operativo:
Es el software base que administra los recursos del computador o servidor. Permite ejecutar aplicaciones y gestionar procesos, archivos y conexiones de red.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador. Se utiliza para desarrollar servidores y aplicaciones web.

Aplicación server.js:
Es el archivo que contiene la lógica del servidor. Define las rutas y las respuestas que se enviarán a los usuarios cuando accedan al servicio.

Puerto:
Es un punto de comunicación que permite al servidor recibir solicitudes. En esta práctica se utiliza el puerto 3000 para atender las peticiones.

Logs:
Son registros que almacenan eventos, errores y actividades del sistema. Permiten monitorear el funcionamiento del servidor y facilitar la solución de problemas.
